# \# Keep Going \*\*v1.2 設計文件\*\*

# 

# \## \*\*1. 專案概述\*\*

# 

# Keep Going 是一款專為跨領域創作者設計的 Windows 工作進度紀錄工具。透過「自動偵測視窗」與「智能標籤分類」，讓使用者在下班前能一鍵記錄多個專案的視覺進度，並在隔天開工或任何需要時刻，透過獨立檢視器比對跨日期的進度演化歷程，協助快速找回工作節奏並精確掌握專案成長。

# 

# \---

# 

# \## \*\*2. 核心功能規格\*\*

# 

# \### \*\*2.1 智能視窗偵測與分類 (Smart Detection)\*\*

# 

# \- \*\*自動掃描\*\*：系統啟動時會抓取目前所有非縮小化的視窗標題與關聯的進程（.exe）。

# \- \*\*瀏覽器深度偵測 (CDP Integration)\*\*：

# &#x20;   - 針對 Chrome 或 Edge 瀏覽器，透過遠端偵錯連接埠 (預設 9222) 呼叫 Chrome DevTools Protocol。

# &#x20;   - 即使瀏覽器標題僅顯示當前分頁，系統仍能遍歷所有開啟中的 Tab 標題與 URL。

# \- \*\*預設規則映射\*\*：根據預定義規則自動將視窗或分頁歸類：

# &#x20;   - 繪畫 (Art)：偵測到 Photoshop.exe、ClipStudioPaint.exe 等。

# &#x20;   - 程式 (Dev)：偵測到 Code.exe (VS Code)、devenv.exe (Visual Studio) 等。

# &#x20;   - 寫作 (Writing)：透過 CDP 偵測到 URL 包含 notion.so 的所有獨立分頁。

# \- \*\*手動調整\*\*：使用者可於介面中勾選/取消勾選特定視窗或分頁，或手動變更其分類標籤。

# 

# \### \*\*2.2 精準截圖邏輯 (Targeted Capture)\*\*

# 

# \- \*\*視窗置頂與同步\*\*：執行截圖前，程式會自動將目標視窗喚醒至最上層。針對瀏覽器分頁，程式會透過 CDP 指令發送 Page.bringToFront 以切換至目標分頁，並加入 300ms 延遲確保渲染完成。

# \- \*\*座標裁剪\*\*：精確抓取目標視窗的 (x, y, width, height) 範圍。

# \- \*\*批次執行\*\*：支援一次勾選多個視窗/分頁，程式將自動循環執行「切換、確保置頂、截圖、儲存」流程。

# 

# \### \*\*2.3 進度回顧 (Morning Review)\*\*

# 

# \- \*\*定時觸發\*\*：配合 Windows 工作排程器，於每日設定時間或開機登入時啟動。

# \- \*\*標籤篩選回顧\*\*：使用者可選擇特定標籤，程式會顯示該標籤下「最後一筆紀錄」的截圖與備註，方便使用者承接上一次的工作進度。

# 

# \### 2.4 歷史進度檢視器 (Independent Progress Inspector)

# 

# \- \*\*按需啟動\*\*：僅在使用者需要確認進度時手動開啟獨立程式。

# \- \*\*多日期複選比對\*\*：檢視器介面支援依據標籤（如：繪畫、程式）篩選歷史紀錄，使用者可從清單中自由勾選多個不同的日期（例如：昨天與前天，或是上週至今天）。

# \- \*\*自適應並排顯示\*\*：選中多張截圖後，系統會將其以縮圖並排展示，游標在其縮圖上懸浮則會顯示完整資訊（包含備註等）。若全螢幕檢視，會顯示時間軸以及當時的備註，拖動時間軸後會快速導引至對應日期的紀錄。

# \## \*\*3. 技術架構\*\*

# 

# \### \*\*3.1 技術棧\*\*

# 

# \- \*\*程式語言\*\*：Python 3.10+

# \- \*\*視窗管理\*\*：pygetwindow、pywinauto。

# \- \*\*瀏覽器通訊\*\*：requests 或 pychrome (用於對接 Chrome DevTools Protocol)。

# \- \*\*影像處理\*\*：Pillow (PIL)。

# \- \*\*系統資訊\*\*：psutil。

# \- \*\*使用者介面\*\*：PyQt6。

# \## \*\*4. 系統工作流程\*\*

# 

# \### \*\*下班存檔流程 (Archive Flow)\*\*

# 

# 1\. \*\*偵測\*\*：程式掃描系統視窗，並同步透過 CDP 撈取瀏覽器全部分頁清單。

# 2\. \*\*分類\*\*：依據映射表自動勾選。若有多個相同標籤的分頁 (如兩個 Notion)，將各自列出。

# 3\. \*\*輸入\*\*：使用者在對應欄位輸入備註。

# 4\. \*\*執行\*\*：執行「確認存檔」，針對一般視窗使用 pywinauto 置頂，針對瀏覽器分頁使用 CDP 切換 Tab。

# 5\. \*\*寫入\*\*：依據當前日期寫入對應月份的 history\_YYYY\_MM.json。

# 

# \### \*\*早晨回顧流程 (Review Flow)\*\*

# 

# 1\. \*\*啟動\*\*：Windows 自動啟動 `review.py`。

# 2\. \*\*選擇\*\*：使用者選擇今日要進行的標籤（如：程式）。

# 3\. \*\*展示\*\*：視窗彈出，顯示已經被使用者上次工作時的資訊。

# 

# \### 進度檢視流程 (Inspection Flow)

# 

# 1\. 啟動：使用者主動執行 \[inspect.py](http://inspect.py/)。

# 2\. 篩選：使用者點選分類標籤與欲比對的多個日期。

# 3\. 顯示：程式開啟一個新視窗，將選定的歷史截圖以並排方式呈現在螢幕上，供使用者隨時查閱。

# \## \*\*6. 未來擴充性 (Roadmap)\*\*

# 

# \- \*\*雲端備份\*\*：支援將資料同步至 OneDrive/Dropbox。

# \- \*\*自動對比演算法\*\*：使用 OpenCV 自動計算兩張截圖的差異面積並高亮顯示。

# \- \*\*動態標籤學習\*\*：當使用者多次將特定視窗手動分類後，系統自動學習並更新對應表。

# \- \*\*縮時攝影\*\*：累積一週進度後，自動合成一段 10 秒的專案成長縮時影片。
